# Contributor Covenant Code of Conduct

We pledge to make participation in this project a harassment-free experience for everyone.
Contributors should communicate respectfully, assume good intent, accept evidence-based review,
and avoid personal attacks or discriminatory behavior.

Unacceptable behavior includes harassment, intimidation, publishing another person's private
information, and sustained disruption. Maintainers may remove or reject contributions and limit
participation when necessary to protect the community. Report conduct concerns privately to the
repository maintainers.

This policy is adapted from the Contributor Covenant, version 2.1.
