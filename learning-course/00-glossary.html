HOW TO READ

先认识四组最容易混淆的词

LLM、Agent、Agent Host

LLM 负责生成与推理；Agent 在 LLM 之外还有工具、状态和行动；Host 是启动 Agent 并提供运行环境的系统。

Skill、Prompt、Package

Prompt 是文本上下文；Skill 是可复用工作能力；Package 是承载该能力的完整文件与依赖集合。

Eval、Grader、Gate

Eval 产生证据与分数；Grader 是其中一个评分角色；Gate 根据冻结规则决定候选能否继续。

Train、Validation、Deployable

Train 反馈可以指导搜索；Validation 对优化器保密；只有通过后才是 deployable 候选。

阅读约定

课程第一次出现专有词时尽量写成“中文（English）”。代码字段保留英文，因为它们是实际 schema 名称；旁边会给中文解释。

本章面试问答

为什么代码字段不全部翻译成中文？
schema 与 Python API 的英文名是稳定交换契约，强行翻译会让学习内容与代码脱节。课程在第一次出现时解释含义，之后保留原字段名。
Candidate 和 deployable candidate 有什么区别？
Candidate 只是待验证的新 Package 版本；deployable candidate 已逐层通过结构、安全、train 与 held-out Gate。两者之间可能隔着多次拒绝。

术语学习方法

不必一次背完。先记住 Core/Host、Package、Eval/Gate、Train/Validation 四组边界，后面遇到词再点开解释。
